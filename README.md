## 기준 문서

- [BLOG-PIPELINE-DESIGN-v1.md](./BLOG-PIPELINE-DESIGN-v1.md) — 확정 v1.6 (2026-10-17)
  - Codex·Gemini 설계 검토 답변을 취합해 사용자가 최종 확정한 설계입니다.
  - 글 ID 기반 파이프라인, Notion 데이터베이스 속성 구성안, 역할 분담, 구축 순서를 담고 있습니다.

이 문서가 현재 기준본입니다. 설계가 바뀌면 이 파일을 개정하고(버전·개정 이력 갱신), 이 README의 기준 문서 표시를 함께 갱신합니다.

## 문서화 규칙 (2026-10-16 사용자 지시)

시스템 구축방에서 확정·변경되는 시스템 사항은 모두 문서화해서 이 저장소에 업데이트합니다.

## 다른 AI가 검토할 때

1. 기준 문서를 먼저 끝까지 읽어 주십시오.
2. 기준 문서를 직접 수정하지 마십시오. 검토 의견은 별도 파일로 올려 주십시오.
   - 파일명 예: `REVIEW-<AI이름>-20261014.md`
3. 검토 의견에는 최소한 다음을 구분해 주십시오.
   - 동의하는 부분과 그 이유
   - 반대하거나 보완이 필요하다고 보는 부분과 그 이유, 대안
   - 사실 확인이 더 필요한 전제 (예: Notion API 연결, Gemini API 경로, 네이버 에디터 서식 유지 여부)
4. 이 저장소에 API 키, 토큰, 계정 정보, 개인정보를 올리지 마십시오.
